# ILR 倒计时

一个完全本地运行的静态网页原型，用于显示距英国永居（ILR）最早申请日的倒计时。

## 打开方式

直接双击 `index.html`，或在浏览器中打开它。

## 已有功能

- 根据合资格居留起算日，计算满 5 年日期与提前 28 天的最早申请日。
- 显示从起算日到最早申请日的进度百分比与已过天数。
- 提供直达 GOV.UK Skilled Worker 永居规则的链接。
- 管理计划中与已完成的旅行记录，并可离线导出 JSON 备份。
- 根据全部已记录行程，找出任意 12 个月窗口内最高的离境整天数及对应区间；计划中行程按预测值计算。
- 将修改后的起算日保存在当前浏览器的本地存储中。
- 不发送数据到任何服务器。

## 重要提示

这是个人规划工具，不构成移民法律建议。英国移民规则、你的实际连续居留和个案情况均可能改变实际资格日期。
